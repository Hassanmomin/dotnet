b. Create an application to print Floyd’s triangle till n rows in C#.

Aim: To create a C# application that prints Floyd’s Triangle up to n rows.

Algorithm
        1. Start the program.

        2. Read the number of rows n from the user.

        3. Initialize a variable num = 1.

        4. Use an outer loop from 1 to n for rows.

        5. Use an inner loop to print numbers in each row.

        6. Print num and increment it.

        7. Move to the next line after each row.

        8. Stop the program.

C# Program (Console Application)
Program.cs

using System;

class Program

{

    static void Main(string[] args)

    {

         int n, num = 1;

         Console.Write("Enter the number of rows: "); n = Convert.ToInt32(Console.ReadLine());

         for (int i = 1; i <= n; i++)

         {

             for (int j = 1; j <= i; j++)

            {

                Console.Write(num + " "); num++;

            }

            Console.WriteLine();

        }

        Console.ReadLine();

    }

}
